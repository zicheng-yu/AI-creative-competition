### 1.2 核心结论：`ElectroBench-JS` 标准化数据集 72h 构建方案
- **现实缺口**：全球范围内**不存在现成公开的“中国国标 `GB/T 4728 / GB 7251` 低压成套开关柜（GGD/MNS/GCS/KYN28）一次系统图 + 二次控制原理图 + 规范违规注入 + 标准 BOM 真值”一体化数据集**。
- **72h 最优工程策略（真公开 + 强合成 + 可复现）**：
  1. **公开泛化子集**：接入 `CGHD` 与 Roboflow `EplanSymbols` / `single line diagram` 样本，证明视觉模型跨风格泛化能力；
  2. **国标成套程序化合成子集（核心交付）**：用 Python `ezdxf` 基于 `GB/T 4728` / `GB/T 5094`（`QF/QS/KM/FR/FU/TA/TV/SPD` 等 25+ 符号）程序化生成高保真 **一次配电系统图** 与 **二次电机启停/正反转互锁原理图**（同时输出原生矢量 DXF、矢量 PDF、高分 PNG 与模拟扫描倾斜/模糊/噪点退化件），**由生成器同步导出 100% 精确的 COCO 框、规格属性 JSON、Netlist 拓扑边与标准 BOM CSV**；
  3. **规范缺陷可控注入测试集**：在合成器中精确注入 4 类违规（上下级断路器额定电流级差倒挂、导线截面积载流量低于脱扣电流、电机回路缺失热继电器/熔断器、正反转双接触器缺失常闭互锁接点），同步生成缺陷真值坐标与命中 `GB 50054 / GB 7251` 条款编号。

## 二、可直接复用的开源解决方案与代码栈

| 环节 | 推荐开源项目 / 库 | 核心能力与复用方式 |
| :--- | :--- | :--- |
| **矢量 CAD / PDF 解析** | `mozman/ezdxf` + `PyMuPDF (fitz)` | 直接解析 DXF `LINE/LWPOLYLINE/ARC/CIRCLE/INSERT(Block)` 与 `TEXT/MTEXT` 精确坐标；用 `ezdxf.disassemble` 拆解嵌套图块，天然兼容“散线画符号”场景 |
| **矢量 PDF → 拓扑 Netlist** | `D4NGYY/schematic-extractor` | YOLO 符号检测 + 几何 BFS 追踪 T 型节点/实心连接点，重建 `Components ↔ Nets` 图并导出 JSON/SPICE/KiCad——**架构与我方高度同构，可直接借鉴拓扑追踪逻辑** |
| **光栅图 → 网表全链路** | `JKc66/CircuitVision` | `YOLOv11` 符号检测 + `SAM 2.1` 分割 + VLM 深度 OCR 文本归一化 → 输出网表 |
| **大画幅工程图滑窗检测** | `obss/sahi` + `mgupta70/PID_Symbol_Detection` | 针对 A1/A0 等效 4000×6000 px 电气图纸微小符号，使用 SAHI 重叠切片 + NMS 合并显著降低漏检率 |
| **电气 OCR 与 VLM 精修** | `PaddleOCR` + `Qwen2.5-VL`（局部 ROI 512×512 裁片） | PaddleOCR 配电气专用词典（`QF/KM/3P/In=63A/YJV-4×25+1×16`）；仅对低置信度歧义区域调用 VLM，兼顾速度（≤15s/图）与非标简写归一化精度 |
| **图计算与合规规则** | `NetworkX` + 确定性规则引擎 + 轻量化混合 RAG | 基于 `NetworkX` 做父子配电树遍历（级差校核）、路径可达性检验（二次急停与互锁校核），并按条款 ID 精确检索 `GB 50054 / GB 7251` 原文 |

## 三、深度竞品分析（含 Werk24 专项拆解）

### 3.1 重点竞品专项拆解：**Werk24**（`werk24.io`）
- **定位与能力**：德国 AI 工程图纸解析 API 标杆（提供 REST API、Webhook 与官方 Python SDK `pip install werk24`），无需脆弱的 PDF→DXF 转换，直接从 PDF/TIFF/PNG/JPEG 抽取带像素坐标和置信度的结构化 JSON。
  - 强项 1：**标题栏与嵌入式 BOM 表**（图号、材质如 `20MnCr5`、重量、版本表、标准紧固件 BOM 表）；
  - 强项 2：**机械制造信息 PMI 与 GD&T**（尺寸公差、配合等级 `H7/G6`、螺纹、沉头孔、表面粗糙度 `Ra/Rz`、形位公差）；
  - 强项 3：**可制造性洞察**（基于 `DIN 8580` 识别车/铣/热处理/表面处理工艺与毛坯包络体积，服务机加工快速报价）。
- **核心边界与对本赛题的启示（写进 PPT & 计划书的高分洞察！）**：
  1. **机械加工强、电气拓扑弱**：Werk24 深度优化对象是**机械零件加工图与装配图**，并非复杂的多页电气一次系统图/二次控制原理图，**不具备电气连线交叉消歧与 Netlist 拓扑重建能力**；
  2. **仅抽取现成 BOM 表格，无法“由图算量”**：成套电气招标一次图往往没有现成汇总 BOM 表，必须从图形符号 + 旁注规格 + 回路拓扑中逐项统计汇总；
  3. **缺乏中国国标合规审计与本地化私有部署**：基于 ISO/ASME/DIN 体系且为海外云端 API，无法校验 `GB 50054 / GB 7251` 上下级断路器级差、电缆载流量与二次互锁逻辑，也难以满足国内成套厂图纸“不出厂区”的安全合规要求。
  - **可借鉴亮点**：Werk24 的**按需请求模块（Asks）+ 每个提取字段强制附带 `bbox` 坐标与 `confidence` 置信度**的 API 设计非常优雅，我方前后端接口契约（`YOU-261`）可直接对标该体验！
